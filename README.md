Second-Wave Sniper is a pump.fun paper-trading bot for the make.fun replay: it never buys the launch, only coins 60–300 slots old whose creator never sold and where at least twelve distinct buyers are still arriving, stakes 0.02 SOL per coin, and exits fast on a stop loss, a take profit at a double, a trailing stop, or fading flow, with tiny probe round trips keeping the run above the twenty-coin guardrail. On the published dev window it lost 0.018 SOL with a 0.18% maximum drawdown across 28 coins.

## Run it

node <kit>/cli/makefun.mjs grade-local --kit <kit> --bot . --driver docker --bundle <transcripts.tar.gz>
